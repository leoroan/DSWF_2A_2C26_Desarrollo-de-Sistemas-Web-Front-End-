# Prompts — Desarrollo del Portfolio

Esta branch contiene los prompts utilizados como parte del proceso de
desarrollo de la **PFO1 — Landing de portafolio**.

El objetivo de conservarlos es documentar de manera transparente cómo se
utilizaron herramientas de inteligencia artificial durante las distintas
etapas del desarrollo.

## 📂 Contenido

| Archivo                                                            | Etapa         | Descripción                                                                                           |
| ------------------------------------------------------------------ | ------------- | ----------------------------------------------------------------------------------------------------- |
| [`01-planificacion-portfolio.md`](./01-planificacion-portfolio.md) | Planificación | Prompt utilizado para definir el contexto, los requisitos y la propuesta inicial del portfolio.       |
| [`02-correcciones-portfolio.md`](./02-correcciones-portfolio.md)   | Revisión      | Prompt utilizado para revisar y ajustar la implementación inicial del portfolio.                      |
| [`03-rubrica-de-evaluacion.md`](./03-rubrica-de-evaluacion.md)     | Integración   | Prompt utilizado para implementar una vista interactiva de la rúbrica de evaluación dentro de la SPA. |

## 🔄 Proceso

El desarrollo se documentó mediante distintas etapas:

1. **Planificación:** se utilizó ChatGPT para analizar los requisitos y
   construir el contexto inicial para el desarrollo del portfolio.

2. **Implementación y revisión:** se utilizó Cline dentro de Visual Studio
   Code, utilizando DeepSeek V4-Flash, para implementar la propuesta y
   realizar los ajustes necesarios sobre la implementación inicial.

3. **Integración de la rúbrica:** se utilizó un nuevo prompt para incorporar
   la rúbrica de evaluación como una experiencia interactiva dentro de la
   misma SPA, accesible desde la barra de navegación y sin abandonar la
   página actual.

Los prompts se conservan como registro del proceso y no representan por sí
solos el resultado final del proyecto. Las propuestas generadas fueron
revisadas, adaptadas y validadas durante el desarrollo.

## 🤖 Uso de IA

Esta branch complementa la sección de uso de IA documentada en la branch
principal.

Los archivos contienen los prompts utilizados durante el desarrollo para
permitir consultar posteriormente qué instrucciones fueron proporcionadas a
las herramientas utilizadas y cómo evolucionó el proceso de implementación.

La IA se utilizó como herramienta de apoyo para planificación, revisión,
implementación y mejora de la solución. Las decisiones finales de diseño,
estructura, integración y contenido fueron revisadas durante el desarrollo
del proyecto.
