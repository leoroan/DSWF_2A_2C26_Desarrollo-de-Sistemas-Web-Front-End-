# Prompts — Desarrollo del Portfolio

Esta branch contiene los prompts utilizados como parte del proceso de
desarrollo de la **PFO1 — Landing de portafolio**.

El objetivo de conservarlos es documentar de manera transparente cómo se
utilizaron herramientas de inteligencia artificial durante el desarrollo.

## 📂 Contenido

| Archivo | Etapa | Descripción |
|---|---|---|
| [`01-planificacion-portfolio.md`](./01-planificacion-portfolio.md) | Planificación | Prompt utilizado para definir el contexto y la propuesta inicial. |
| [`02-correcciones-portfolio.md`](./02-correcciones-portfolio.md) | Revisión | Prompt utilizado para revisar y ajustar la implementación inicial. |

## 🔄 Proceso

El desarrollo se realizó en dos etapas principales:

1. **Planificación:** se utilizó ChatGPT para analizar los requisitos y
   construir un contexto inicial para el desarrollo.
2. **Implementación y revisión:** se utilizó Cline dentro de Visual Studio
   Code, utilizando DeepSeek V4-Flash, para implementar la propuesta y
   realizar posteriormente los ajustes necesarios.

Los prompts se conservan como registro del proceso y no representan por sí
solos el resultado final del proyecto. La implementación fue revisada y
adaptada durante el desarrollo.
