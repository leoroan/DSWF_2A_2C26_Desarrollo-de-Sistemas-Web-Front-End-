# PFO1 — Landing de portafolio

## 📌 Descripción

Este repositorio contiene la implementación de la **PFO1 (Práctica Formativa Obligatoria 1)** de la materia **Desarrollo de Sistemas Web (Front End)** del **IFTS N°29**.

El objetivo de la actividad fue desarrollar una **landing personal de portafolio** utilizando HTML y CSS, presentando información personal, habilidades, medios de contacto y una sección de contenido libre.

La propuesta busca combinar los requisitos técnicos de la consigna con una presentación personal sencilla, clara y responsive.

## 🎯 Objetivos de la PFO1

La propuesta consistió en desarrollar una landing que incluyera:

* Nombre y apellido.

* Habilidades y tecnologías.

* Una sección personal de elección.

## 🎨 Decisiones de diseño

La interfaz fue planteada buscando un equilibrio entre **simplicidad, legibilidad y presentación profesional**.

Se optó por una estructura visual dividida en secciones para que la información pueda recorrerse fácilmente:

1. **Presentación:** identificación personal y una breve descripción.
2. **Sobre mí:** información relacionada con el perfil y el recorrido académico.
3. **Habilidades:** tecnologías y áreas de interés.
4. **Proyectos:** espacio destinado a mostrar trabajos realizados.
5. **Sección personal:** contenido elegido para aportar una dimensión más personal al portafolio.
6. **Contacto:** acceso a los medios disponibles para conocer más sobre el trabajo realizado.

El diseño busca evitar una interfaz excesivamente cargada y prioriza el espacio, la jerarquía visual y la facilidad de lectura.

También se incorporaron elementos interactivos y una animación sutil para darle mayor dinamismo a la página sin que interfieran con la navegación.

### 📱 Diseño responsive

La landing fue pensada para adaptarse a diferentes tamaños de pantalla.

En dispositivos pequeños, los contenidos se reorganizan verticalmente, mientras que en pantallas más grandes se aprovecha el espacio disponible para presentar la información de forma más horizontal.

La intención es que la página mantenga una experiencia consistente tanto desde una computadora como desde un dispositivo móvil.

## 🧱 Estructura y tecnologías utilizadas

La PFO1 fue desarrollada utilizando tecnologías web estándar:

* **HTML5** para la estructura y el contenido.
* **CSS3** para los estilos, composición visual y responsive design.
* **JavaScript** para los comportamientos necesarios.
* **Google Fonts** para la tipografía.
* **Git y GitHub** para el control de versiones y publicación del código.
* **Vercel** para la publicación del proyecto.

Se utilizaron elementos semánticos como `header`, `nav`, `main`, `section`, `article`, `figure` y `footer`, buscando que la estructura del documento represente correctamente el contenido.

## ♿ Accesibilidad

Se tuvieron en cuenta algunos aspectos básicos de accesibilidad durante el desarrollo:

* Uso de HTML semántico.
* Textos alternativos mediante `alt` en imágenes.
* Etiquetas `label` asociadas a los campos del formulario.

La accesibilidad se considera parte del desarrollo de la interfaz y no solamente una característica visual adicional.
